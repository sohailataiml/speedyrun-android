# Source material: from gene to protein

**Provenance note:** original content written for this project, same terms
as `source_material.md` — standard molecular biology, original wording and
organisation, not copied from any copyrighted source. Maps to AAMC content
category **1B** (transmission of genetic information from the gene to the
protein); cards carry `topic::central_dogma`. Every card must cite a chunk
ID (`cd-01` … `cd-08`).

## cd-01: The overall flow

The central dogma describes the normal direction of information transfer:
DNA is transcribed into RNA, and RNA is translated into protein. DNA also
replicates to produce more DNA. The dogma is a statement about the usual
direction, not an absolute prohibition — retroviruses carry reverse
transcriptase and copy RNA back into DNA, which is exactly why they are a
favourite exam example of an apparent exception.

## cd-02: DNA structure and antiparallel strands

DNA is a double helix of two strands running antiparallel, one oriented
5' to 3' and the other 3' to 5'. The backbone is sugar-phosphate; the
bases point inward and pair specifically, adenine with thymine by two
hydrogen bonds and guanine with cytosine by three. Because G-C pairs have
an extra hydrogen bond, regions rich in G and C take more energy to
separate, which is why they have higher melting temperatures.

## cd-03: Replication is semiconservative

When DNA replicates, each parent strand serves as a template for a new
partner, so every daughter molecule contains one old strand and one newly
synthesised strand. This is what "semiconservative" means. DNA polymerase
can only add nucleotides to a free 3' hydroxyl, so synthesis always
proceeds 5' to 3'. That constraint forces one strand to be built
continuously toward the replication fork while the other is built in
short fragments pointing away from it, later joined together.

## cd-04: Transcription

Transcription copies one strand of DNA into RNA using RNA polymerase.
Only one strand — the template strand — is read; the other, the coding
strand, matches the RNA sequence except that RNA carries uracil where DNA
carries thymine. RNA polymerase, unlike DNA polymerase, does not require
a primer to begin. The immediate product in eukaryotes is a precursor
that must be processed before it can leave the nucleus.

## cd-05: RNA processing in eukaryotes

Eukaryotic pre-mRNA undergoes three main modifications. A modified
guanine cap is added at the 5' end, a string of adenines called the poly-A
tail is added at the 3' end, and introns are removed by splicing while
the remaining exons are joined. The cap and tail protect the transcript
from degradation and assist in export and ribosome binding. Because a
single transcript can be spliced in more than one way, alternative
splicing lets one gene yield several distinct proteins.

## cd-06: The genetic code

The code is read in three-base units called codons, each specifying one
amino acid or a stop signal. It is degenerate — most amino acids are
specified by more than one codon — but it is unambiguous, since any given
codon specifies only one amino acid. It is also nearly universal across
organisms. AUG serves both as the start codon and as the codon for
methionine, and three codons signal termination rather than coding for
any amino acid.

## cd-07: Translation

Translation occurs on ribosomes, which assemble from a large and a small
subunit around the mRNA. Transfer RNAs deliver amino acids; each tRNA
carries an anticodon that base pairs with the matching mRNA codon,
ensuring the right amino acid is added. The ribosome catalyses peptide
bond formation between the growing chain and the incoming amino acid, and
moves along the message codon by codon until it reaches a stop codon, at
which point the finished polypeptide is released.

## cd-08: Mutations and MCAT traps

A point mutation changes a single base. If the new codon still specifies
the same amino acid the mutation is silent, thanks to degeneracy; if it
specifies a different amino acid it is missense; if it creates a stop
codon it is nonsense and truncates the protein. Insertions or deletions
that are not multiples of three shift the reading frame and typically
garble everything downstream, which is why frameshifts are usually far
more damaging than point mutations. A frequent trap is forgetting that
the coding strand, not the template strand, reads the same as the mRNA.
